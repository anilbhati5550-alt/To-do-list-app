# ToDo-List-project
A simple web-based To-Do List application that allows users to add, mark as complete, and delete tasks. Built using HTML, CSS, and JavaScript, this project is ideal for beginners to practice DOM manipulation and basic web development concepts.

Features
- **Add Tasks**: Input tasks with ease using the text box.
- **Mark as Complete**: Strike through tasks to indicate completion.
- **Delete Tasks**: Remove tasks from the list when they're no longer needed.
- **User-Friendly Interface**: Clean and responsive design.

Technologies Used
- **HTML**: Provides the structure of the app.
- **CSS**: Enhances the visual styling and layout.
- **JavaScript**: Handles functionality like adding, deleting, and completing tasks.

 How to Use
1. Clone the repository:
   ```bash
   git clone https://github.com/durgaprasadys/todo-list.git
2. Open the index.html file in a browser to start the application.
3. Use the input box to type a new task and click the Add Task button.
4. Manage your tasks:
- Click Complete to mark tasks as done.
- Click Delete to remove tasks.
